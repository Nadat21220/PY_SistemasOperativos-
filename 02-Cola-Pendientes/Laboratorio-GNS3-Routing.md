## Descripción

Configurar topología de red con 3 routers en GNS3. Implementar OSPF y BGP, verificar convergencia de rutas. Documentar configuración y resultados.

## Pasos / Subtareas

- [ ] Instalar/verificar GNS3
- [ ] Crear topología de red (3 routers + switches)
- [ ] Configurar IPs en interfaces
- [ ] Implementar OSPF
- [ ] Implementar BGP
- [ ] Probar alcanzabilidad (ping, traceroute)
- [ ] Documentar con capturas
- [ ] Entregar archivo .gns3 + reporte
