## Descripción

Serie de 5 ejercicios de iluminación en Blender. Desde iluminación de 3 puntos hasta iluminación dinámica. Renderizar cada escena.

## Pasos / Subtareas

- [x] Setup básico de escena
- [ ] Ejercicio 1: Three-point lighting
- [ ] Ejercicio 2: Product lighting
- [ ] Ejercicio 3: Outdoor/Natural lighting
- [ ] Ejercicio 4: Interior realistic
- [ ] Ejercicio 5: Iluminación artística (libre)
- [ ] Render final de cada escena
- [ ] Hacer comparativas de setup

## Notas / Contexto

Parte de asignatura 3D Graphics. Cada ejercicio: ~2 horas. Pueden usar modelos 3D pre-hechos. Enfoque: entender cómo luz afecta atmósfera.
