## Descripción

Modelar cabeza humana realista en Blender usando técnicas de sculpting y retopology. Incluir texturas básicas de piel.

## Pasos / Subtareas

- [ ] Configurar proyecto Blender (UV maps, materiales)
- [ ] Crear base con primitivos
- [ ] Sculpt: formas generales (frente, nariz, boca)
- [ ] Sculpt: detalles (ojos, orejas, arrugas)
- [ ] Retopology (mesh limpia)
- [ ] Texturizar (material de piel)
- [ ] Renderizar en 1920x1080
- [ ] Exportar render final

## Notas / Contexto

Proyecto creativo. Pueden inspirarse en referencias de artistas. Tiempo estimado: 8-10 horas. Usar blend file con nombrado claro.
